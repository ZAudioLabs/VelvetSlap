# Velvet Slap (Z Audio Labs)
Requisitos: CMake 3.22+, compilador C++17 (Xcode / VS 2022 / gcc) e internet (baixa o JUCE).
    cmake -B build -DCMAKE_BUILD_TYPE=Release
    cmake --build build --config Release
O VST3/AU/Standalone e gerado em build/VelvetSlap_artefacts/ e copiado para as pastas do sistema.
